# Refleksi Modul 03 — CSS dan Box Model

1. Konflik selector yang ditemukan adalah adanya aturan CSS yang perlu dirapikan agar tampilan elemen menjadi konsisten. Aturan yang lebih sesuai kemudian digunakan oleh browser.

2. Elemen yang ukurannya perlu diperhatikan adalah kartu peralatan. Ukurannya diperiksa menggunakan DevTools melalui Box Model.

3. Perubahan yang paling meningkatkan keterbacaan adalah penggunaan warna, padding, border, radius, dan spacing yang lebih konsisten.

4. Spacing masih perlu diperhatikan agar tidak terlalu acak. Penggunaan custom property membantu membuat jarak lebih konsisten.

5. Kebiasaan debugging yang akan digunakan lagi adalah memeriksa elemen melalui DevTools, melihat aturan CSS yang aktif, dan mengecek Box Model sebelum mengubah kode.
